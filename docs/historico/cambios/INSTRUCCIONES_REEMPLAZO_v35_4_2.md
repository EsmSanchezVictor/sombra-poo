# Reemplazo a Proyecto Sombra v35.4.2

## Opción recomendada
Usar `archivos_reemplazo_forma_copa_v35_4_2.zip` sobre una instalación v35.3, v35.4 o v35.4.1.

1. Cerrar Proyecto Sombra y VS Code si tiene archivos abiertos.
2. Extraer el ZIP en la raíz del proyecto (`d:\GitHub\sombra-poo`), aceptando reemplazar archivos.
3. Verificar que existan:
   - `diseno.py`
   - `core\crown_shapes.py`
4. Puede eliminarse cualquier archivo residual llamado `dise�o.py` o una copia antigua de `diseño.py`; Proyecto Sombra ya no depende de ese nombre para arrancar.
5. Ejecutar `main.py`.

El paquete de reemplazo es acumulativo desde v35.3: no necesita instalar primero v35.4.
