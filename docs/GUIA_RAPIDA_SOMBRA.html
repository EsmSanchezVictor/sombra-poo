PROYECTO SOMBRA · v35.6-etapa4.3.6

Guía rápida

Empezá un proyecto y obtené tu primer resultado por fotografía o por simulación de una escena.

Manual completoAlcance y límites

1. Abrí un proyecto

En Windows, abrí el acceso directo si ya tenés el programa instalado. Si usás el ZIP de código fuente, ejecutá PREPARAR_SOMBRA.cmd la primera vez y luego ABRIR_SOMBRA.cmd.

En una instalación limpia, creá el administrador. Iniciá sesión y elegí Crear proyecto, Abrir proyecto o Importar archivo .3es. Para un proyecto nuevo, seleccioná unidades, nombre y ubicación. La barra y los paneles aparecen cuando el proyecto se abre.

2A. Analizá una foto

  1. En Temperatura, completá fecha, hora local y temperatura del aire. Verificá la ubicación del proyecto.
  2. En Sombra, elegí Cargar imagen. Marcá el área de cálculo y una referencia iluminada de la misma superficie. Seguí el botón violeta para confirmar.
  3. Revisá Ver máscara sombra / sol. Usá Generar curva de nivel para obtener el mapa estimado de Tmrt. Si aplicás exclusiones de materiales, volvé a generar la curva.

2B. Simulá una escena

  1. En Edición, elegí Generar plano 2D o Abrir Excel. Usá Añadir árbol o Añadir estructura y marcá la posición en el plano.
  2. Revisá fecha, hora, ubicación y meteorología antes de comparar alternativas. Si vas a usar Modelo, cargá los datos en ese panel y elegí Ejecutar modelo.
  3. Usá Generar vista 3D para explorar el resultado. Para una comparación válida, mantené las mismas condiciones y cambiá solo la intervención que querés estudiar.

3. Conservá el trabajo

Usá Archivo → Guardar respaldo (Ctrl+S). Para trasladar el proyecto completo, elegí Exportar .3es…. Excel y PDF sirven para compartir datos o informes; para recuperar la escena, conservá el proyecto o su paquete .3es.

Alcance y límites

Sombra estima cobertura de sombra, temperatura superficial y temperatura radiante media (Tmrt), según el flujo y sus entradas. La Tmrt describe la carga radiante; no es temperatura del aire. La máscara fotográfica puede confundir materiales oscuros con sombra.

Validación de campo pendiente. Esta es una versión piloto. Usá los resultados para explorar y comparar escenarios. Antes de basar una decisión técnica en ellos, contrastalos con mediciones.
