# Reemplazo v8

Para actualizar una instalación v7, reemplazar:

- `shadow_temp.py`
- `ui/app_ui.py`

Opcionalmente reemplazar también `test/test_physics.py` para incorporar las nuevas pruebas de regresión.

Después de reemplazar, reiniciar la aplicación y volver a generar la curva de nivel. Las imágenes PNG ya guardadas son estáticas y no incorporan el nuevo hover.
